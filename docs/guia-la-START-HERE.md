# guia.la — planning handoff

guia.la is the reusable white-label destination platform. Cotijuba is the first real destination. The old Cotiju application and its private `luandro/cotiju-app` GitHub repository remain historical references only.

## How to hand off

1. Copy both `guia-la-master-plan.html` and `guia-la-agent-handoff.md` to the agent's workspace.
2. Provide the Markdown prompt to the agent and ask it to read the whole HTML (including collapsed phases).
3. The authorized scope is **review and generation of planning artifacts only**. It should not scaffold the app, deploy services, modify legacy data, or purchase the domain.
4. Review the architecture critique, proposed decisions and detailed playbooks before authorizing implementation.

The `guia.la` domain is an intended brand/domain; ownership has not been verified in these files.
