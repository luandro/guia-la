# ADR-0016. Internationalization from day one

- **Decision register:** D-14
- **Status:** approved — by the owner on 2026-11-22. The i18n library is chosen by a Phase 02 spike.
- **Date:** 2026-11-22
- **Deciders:** owner
- **Phase gate:** 02
- **Reversal cost:** high once strings and routes ship without it
- **Related:** [decision register, D-14](../../planning/decisions.md); D-03 (static export, S1)

## Context

guia.la serves visitors from many countries. Retrofitting i18n after strings, routes and content ship is costly.

## Options considered

| Option | Pros | Cons | Evidence needed |
|---|---|---|---|
| expo-localization + i18next/react-i18next | Mature, wide ecosystem | Runtime catalogs, larger bundle | Phase 02 spike |
| Lingui | Compile-time catalogs, smaller bundle | Smaller RN ecosystem | Phase 02 spike |

## Decision

UI in `en`, `pt-BR`, `es`, `fr`, `nl`, `de` from Phase 02; a missing key fails CI. Localized content with a per-destination default locale; untranslated fallbacks are marked; machine translations are flagged until reviewed. Locale-prefixed web routes with `hreflang` and per-locale OG tags. `Intl` formatting in the destination timezone.

## Evidence

The Phase 02 spike picks the library and measures the per-locale static export (page count, build time) within S1.

**Spike result (Phase 02, 2026-11-22; status unchanged):** i18next + react-i18next + expo-localization chosen over Lingui: no Metro/Babel transform, synchronous init under static rendering ([i18n spike](../features/phase-02-skeleton/i18n-spike.md)). Six catalogs; `pnpm i18n:check` fails naming the locale and key (demo: `nl: missing key common.offlineHint`). Per-locale cost: 49 pages for 7 places (pages ≈ 1 + 6 × (1 + places)).

## Consequences

Six times the static pages; every widget ships six catalogs; translation review becomes part of content operations (Phase 09).
